📘 部署至 GitHub Pages 教學：

  1. 將此單一 HTML 檔案命名為 index.html 並建立一個 GitHub 倉庫（Repository）上傳。
  2. 在 GitHub 倉庫頁面進入 Settings → Pages。
  3. 在 Branch 選擇 main（或 master），資料夾保持 / (root)，點擊 Save。
  4. 稍候 1~2 分鐘即可獲得專屬公開網址（例如：https://your-username.github.io/repo-name/），隨開即用！
